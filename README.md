# Crystal Sheen Abacajen — Portfolio

A personal portfolio website showcasing my background, skills, projects, and educational journey as an Information Systems student.

## About the Project

This portfolio was developed as part of the Progressive Portfolio Website Project. It demonstrates the fundamentals of HTML and CSS through a clean, minimalist black-and-white design.

## Features

- **Introduction** — Personal introduction and career tagline
- **About Me** — Background, hobbies, interests, and goals
- **Skills** — Interactive flip cards showcasing my skills
- **Projects** — Project cards featuring CARA, Smart Shelf, and BCWD Website Redesign
- **Education & Experience** — Educational background displayed in an HTML table
- **Contact Form** — Form with name, email, subject, and message fields
- **Responsive Design** — Layout adjustments for desktop, tablet, and mobile screens
- **Navigation** — Links to the different sections of the portfolio
- **Footer** — Copyright information and back-to-top link

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## Project Structure

```text
portfolio-project/
├── index.html
├── style.css
├── cara.html
├── smartshelf.html

├── README.md

```

The `images/` folder contains the profile photo, skill images, project thumbnails, and project gallery images.

## How to View the Portfolio

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Explore the portfolio sections using the navigation menu.
4. Open the project cards to view their individual project pages.

## Note

This is a static HTML and CSS portfolio. The contact form currently serves as a front-end form and does not send emails.
